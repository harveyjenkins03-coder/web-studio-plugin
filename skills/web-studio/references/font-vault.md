# Font Vault

Curated database of high-quality typefaces for web design. This is Claude's primary reference when selecting fonts, designed to prevent font convergence and ensure every project has a distinctive typographic identity. Always check the banned list and watch list before making any font selection.

---

## BANNED FONTS -- NEVER USE

These fonts are so ubiquitous they signal "default choice" rather than intentional design. Never select them for any project. If a user specifically requests one, suggest the closest alternative from this vault instead.

| Banned Font | Why | Use Instead |
|---|---|---|
| **Inter** | The new Arial. Everywhere. | Geist, Instrument Sans, Figtree |
| **Roboto** | Google's default. Zero personality. | DM Sans, Source Sans 3, Albert Sans |
| **Arial** | The original default sin. | Switzer, Hanken Grotesk |
| **Open Sans** | Aggressively neutral to the point of invisible. | Nunito Sans, Commissioner, Atkinson Hyperlegible |
| **Lato** | Indistinguishable from the above at body sizes. | Plus Jakarta Sans, Outfit |
| **Montserrat** | Every startup landing page 2019--2024. | Sora, Urbanist, Red Hat Display |
| **Poppins** | Geometric sans that lost all edge through overuse. | Lexend, Satoshi, General Sans |
| **Raleway** | Thin-weight trend casualty. | Manrope, Albert Sans |
| **Nunito** | Rounded sans that says nothing. | Nunito Sans (the Sans variant is fine), Figtree |
| **Quicksand** | Rounded geometric with no remaining distinctiveness. | Onest, Gabarito |

---

## WATCH LIST -- USE WITH CAUTION

These are good typefaces trending toward overuse in AI-generated designs. The anti-slop audit may flag them. Prefer alternatives when equally suitable.

- **Space Grotesk** -- Becoming the "cool startup" default. Still valid for developer/tech contexts but pair carefully. Alternative: Schibsted Grotesk, Familjen Grotesk
- **Clash Display** -- Overexposed in design portfolios. Reserve for truly bold editorial use. Alternative: Syne, Bricolage Grotesque
- **Cabinet Grotesk** -- Trending heavily in SaaS. Alternative: Switzer, General Sans
- **Neue Montreal** -- Premium feel eroding through widespread adoption. Alternative: Mona Sans, Hubot Sans

## Category: Editorial Display

Refined serif faces for headlines, hero sections, and editorial layouts. These carry authority, elegance, or literary gravitas.

### Playfair Display
- **Source:** Google Fonts
- **Weights:** 400--900, plus italic
- **Use:** Luxury branding, editorial headlines, hero text. High stroke contrast gives it authority at large sizes.
- **Pairings:** Source Sans 3, Figtree, DM Sans
- **DNA profiles:** The Curator, The Storyteller

### Cormorant Garamond
- **Source:** Google Fonts
- **Weights:** 300--700, plus italic
- **Use:** Literary projects, elegant long-form, fine dining. Exceptionally beautiful at display sizes with its sharp, narrow letterforms.
- **Pairings:** Instrument Sans, Hanken Grotesk, Fira Code
- **DNA profiles:** The Curator, The Artisan

### Baskervville
- **Source:** Google Fonts
- **Weights:** 400, italic
